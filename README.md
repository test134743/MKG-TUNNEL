ប្រសិនបើ Release មានឯកសារ `SHA256SUMS.txt` អ្នកអាចផ្ទៀងផ្ទាត់ឯកសារដែលបានទាញយក៖

```bash
# Linux / macOS
sha256sum MKG.TUNNEL-1.0.2.apk
```

```powershell
# Windows PowerShell
Get-FileHash .\MKG.TUNNEL-1.0.2.exe -Algorithm SHA256
```

## ការដំឡើង

### Android

1. ទាញយកឯកសារ `MKG.TUNNEL-1.0.2.apk`
2. ក្នុង **Settings** អនុញ្ញាត **Install unknown apps** សម្រាប់ Browser ឬ File Manager ដែលអ្នកប្រើ
3. បើកឯកសារ APK ហើយចុច **Install**
4. បើកកម្មវិធី **MKG TUNNEL**

### Windows

1. ទាញយកឯកសារ `MKG.TUNNEL-1.0.2.exe`
2. ចុចពីរដងដើម្បីដំណើរការឯកសារ EXE ហើយធ្វើតាមការណែនាំ
3. បើកកម្មវិធី **MKG TUNNEL**

## របៀបប្រើប្រាស់

1. បើកកម្មវិធី
2. នាំចូលកំណត់រចនាសម្ព័ន្ធ ដោយជ្រើស **Import V2Ray** ឬ **Import Sub**

## គោលការណ៍ប្រើប្រាស់

សូមអានសេចក្ដីសង្ខេបខាងក្រោមមុនប្រើប្រាស់៖

- **មិនធានា ១០០%៖** យើងមិនធានាថាការតភ្ជាប់នឹងមិនដាច់ ១០០% ទេ។ ការតភ្ជាប់អាស្រ័យលើអ៊ីនធឺណិត បណ្ដាញ និងម៉ាស៊ីនមេ។
- **ប្រើឲ្យត្រូវច្បាប់៖** សូមប្រើប្រាស់កម្មវិធីឲ្យស្របតាមច្បាប់ជាធរមាន។ ហាមប្រើសម្រាប់សកម្មភាពខុសច្បាប់ ការវាយប្រហារប្រព័ន្ធ ការបំពានកម្មសិទ្ធិបញ្ញា ឬការផ្ញើ Spam។
- **ការទទួលខុសត្រូវ៖** អ្នកប្រើទទួលខុសត្រូវទាំងស្រុងចំពោះការប្រើប្រាស់របស់ខ្លួន។
- **Config និង Sub៖** កុំចែករំលែក Config ឬ Sub ឯកជនរបស់អ្នក ហើយ Import តែពីប្រភពដែលអ្នកទុកចិត្ត។
- **ហាមលក់បន្ត និងកែប្រែ៖** ហាមលក់បន្ត កែប្រែ ឬចែកចាយកម្មវិធីឡើងវិញដោយគ្មានការអនុញ្ញាត។

គោលការណ៍ពេញលេញ (២៦ មាត្រា) មាននៅលើគេហទំព័រកម្មវិធី។
